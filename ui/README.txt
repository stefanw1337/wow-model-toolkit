Copy D3UI into WoW/Interface/AddOns. In game: /d3ui Paragon, /d3ui SkillPane, /d3ui Traits, /d3ui SkillBar.
/d3ui SkillPane ActiveSkillSelect selects an alternative panel; /d3ui SkillPane list lists panels.
/d3icons [search text] opens the paged icon browser. Escape or Close dismisses windows.
This is a UI conversion workshop, not a functioning Paragon or D3 skills system.
See conversion-report.json for unsupported data. Edit overrides JSON and rebuild into a new output directory.
Register callbacks using D3UI.RegisterHandler(name, function) from a separate addon depending on D3UI.
